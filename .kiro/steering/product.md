# Product Overview

Solar Panel Audit System - A Flutter application for managing and tracking quality audits across solar panel manufacturing processes.

## Core Functionality

- Multi-stage audit management for solar panel production (Sheet Cutting, Cell Cutting, Framing)
- User authentication and role-based access control
- PDF report generation for audit documentation
- MongoDB-based data persistence with cloud and local server support
- Real-time audit statistics and filtering
- Offline-capable with connectivity detection

## Key Features

- Serial number-based audit tracking (SC-, CC-, FR- prefixes)
- Audit verification workflow (auditor → verifier)
- Date-based filtering (today, this week, this month, custom range)
- Search functionality across serial numbers, auditors, and module types
- Connection type switching (local MongoDB or cloud Atlas)
- Image and file attachment support for audit evidence
